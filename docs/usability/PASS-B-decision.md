## F10 ordinary snapshot line reads

Add `patchdiff_read_lines(target_file_id,start_line=1,end_line=null,offset=0,max_chars=null)`. Lines are one-based, end_line inclusive; omitted end selects EOF. Boundaries use LF only, not str.splitlines Unicode separators. Each selected line includes its trailing LF when present. Empty target has one empty line; a trailing LF creates a final empty line. Invalid non-bool integer types, nonpositive line numbers, end<start or line numbers beyond total_lines return invalid_argument. Offset is a nonnegative code-point offset inside the selected range; offset equal to range length is a valid empty final page, greater rejects. max_chars omitted/null defaults4000, positive non-bool values cap8000.

Read current_content/version/current_hash and target identity/type with one ordinary column SELECT under no_autoflush; ignore ORM cache/local target edits and do not refresh or mutate them. Normal service-managed text is already canonical LF; do not silently normalize corrupt storage. Return coherent observed identity, total_chars,total_lines, selected start_line/end_line, absolute range_start/range_end and page start/end, exact text, truncated and next_offset (offset+returned length only when more remains). Output text is at most8000 code points; continuation repeats the same requested line range with next_offset. A later page is a new observation and can change; guards remain necessary. No writes, attempts, locks or editing adapter.
